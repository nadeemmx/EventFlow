GET/bookings

Retrieve a list of all bookings with optional filtering by date, venue, or status.

Request

curl https://api.eventflow.com/v1/bookings \
  -H "Authorization: Bearer $EVENTFLOW_API_KEY" \
  -H "Content-Type: application/json"

Response

{
  "data": [
    {
      "id": "b_xyz789",
      "venue_id": "v_abc123",
      "event_name": "Summer Wedding",
      "date": "2026-08-20",
      "status": "confirmed",
      "guest_count": 180,
      "customer": {
        "name": "Emily Davis",
        "email": "emily@example.com"
      },
      "total": 12500.00,
      "currency": "usd",
      "created_at": "2026-06-01T14:30:00Z"
    }
  ],
  "meta": {
    "total": 42,
    "page": 1,
    "per_page": 25
  }
}

Error Codes

400 Invalid filter parameter401 Unauthorized403 Forbidden
POST/bookings

Create a new booking for a venue. Requires venue availability and valid customer details.

Request

curl -X POST https://api.eventflow.com/v1/bookings \
  -H "Authorization: Bearer $EVENTFLOW_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "venue_id": "v_abc123",
  "event_name": "Corporate Retreat",
  "date": "2026-09-10",
  "start_time": "09:00",
  "end_time": "17:00",
  "guest_count": 50,
  "customer": {
    "name": "Michael Brown",
    "email": "michael@acme.com",
    "phone": "+1-555-987-6543"
  }
}'

Response

{
  "id": "b_xyz790",
  "venue_id": "v_abc123",
  "event_name": "Corporate Retreat",
  "date": "2026-09-10",
  "status": "pending_confirmation",
  "guest_count": 50,
  "total": 4500.00,
  "currency": "usd",
  "created_at": "2026-06-15T10:00:00Z"
}

Error Codes

400 Validation error409 Venue unavailable422 Unprocessable entity
GET/bookings/:id

Retrieve details for a specific booking by its unique identifier.

Request

curl https://api.eventflow.com/v1/bookings/b_xyz789 \
  -H "Authorization: Bearer $EVENTFLOW_API_KEY"

Response

{
  "id": "b_xyz789",
  "venue_id": "v_abc123",
  "event_name": "Summer Wedding",
  "date": "2026-08-20",
  "status": "confirmed",
  "guest_count": 180,
  "special_requests": "Vegetarian meals for 30 guests",
  "customer": {
    "name": "Emily Davis",
    "email": "emily@example.com",
    "phone": "+1-555-456-7890"
  },
  "total": 12500.00,
  "currency": "usd",
  "created_at": "2026-06-01T14:30:00Z",
  "updated_at": "2026-06-10T09:15:00Z"
}

Error Codes

401 Unauthorized404 Booking not found
PUT/bookings/:id

Update an existing booking. Partial updates are supported.

Request

curl -X PUT https://api.eventflow.com/v1/bookings/b_xyz789 \
  -H "Authorization: Bearer $EVENTFLOW_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "guest_count": 200,
  "special_requests": "Updated vegetarian meals count to 40"
}'

Response

{
  "id": "b_xyz789",
  "venue_id": "v_abc123",
  "event_name": "Summer Wedding",
  "date": "2026-08-20",
  "status": "confirmed",
  "guest_count": 200,
  "special_requests": "Updated vegetarian meals count to 40",
  "updated_at": "2026-06-18T11:45:00Z"
}

Error Codes

400 Validation error404 Booking not found409 Conflict
DELETE/bookings/:id

Cancel and delete a booking. May be subject to cancellation policies.

Request

curl -X DELETE https://api.eventflow.com/v1/bookings/b_xyz789 \
  -H "Authorization: Bearer $EVENTFLOW_API_KEY"

Response

{
  "id": "b_xyz789",
  "status": "cancelled",
  "cancelled_at": "2026-06-20T16:00:00Z",
  "refund": {
    "amount": 12500.00,
    "currency": "usd",
    "status": "pending"
  }
}

Error Codes

401 Unauthorized404 Booking not found409 Cannot cancel past event

POST/payments

Process a payment for a booking. Supports major credit cards and digital wallets.

Request

curl -X POST https://api.eventflow.com/v1/payments \
  -H "Authorization: Bearer $EVENTFLOW_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "booking_id": "b_xyz790",
  "amount": 4500.00,
  "currency": "usd",
  "payment_method": "card",
  "card": {
    "number": "4242424242424242",
    "exp_month": 12,
    "exp_year": 2028,
    "cvc": "123"
  }
}'

Response

{
  "id": "p_321fed",
  "booking_id": "b_xyz790",
  "amount": 4500.00,
  "currency": "usd",
  "status": "succeeded",
  "payment_method": "card",
  "card_brand": "visa",
  "last4": "4242",
  "receipt_url": "https://dashboard.eventflow.com/receipts/p_321fed",
  "created_at": "2026-06-15T10:05:00Z"
}

Error Codes

400 Validation error402 Payment failed404 Booking not found
