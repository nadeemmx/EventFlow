Quick Start Guide

Get up and running with EventFlow in minutes. This guide walks you through creating your first booking programmatically.

1

Get Your API Key

Sign in to your EventFlow dashboard and navigate to Settings → API Keys. Click "Generate Key" and copy your secret key. Store it securely.

export EVENTFLOW_API_KEY="sk_live_your_secret_key_here"
2

Make Your First API Call

Verify your integration by fetching available venues. You can use curl or any HTTP client.

curl https://api.eventflow.com/v1/venues \
  -H "Authorization: Bearer $EVENTFLOW_API_KEY" \
  -H "Content-Type: application/json"
3

Create a Booking

Submit a booking request with event details, date, and customer information.

curl -X POST https://api.eventflow.com/v1/bookings \
  -H "Authorization: Bearer $EVENTFLOW_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "venue_id": "v_abc123",
  "event_name": "Annual Gala",
  "date": "2026-12-15",
  "start_time": "18:00",
  "end_time": "23:00",
  "guest_count": 250,
  "customer": {
    "name": "Jane Smith",
    "email": "jane@example.com",
    "phone": "+1-555-123-4567"
  }
}'

Authentication

EventFlow uses API keys for authentication. Include your secret key in theAuthorizationheader of every request. All API requests must be made over HTTPS.

Using API Keys

// Node.js example
const eventflow = require('@eventflow/sdk');

const client = new eventflow.Client({
  apiKey: process.env.EVENTFLOW_API_KEY,
});

async function createBooking() {
  const booking = await client.bookings.create({
    venueId: 'v_abc123',
    eventName: 'Corporate Summit',
    date: '2026-12-15',
  });
  console.log(booking);
}
